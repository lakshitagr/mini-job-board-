# 🧑‍💼 Mini Job Board Application – MERN Stack

This is a mini job board full-stack web application built with React, Node.js, Express, and MongoDB. It allows users to:

- View all job listings
- Add a new job via a form
- View individual job details



---

## 🛠 Tech Stack

- **Frontend**: React.js, JavaScript,Tailwind Css
- **Backend**: Node.js, Express.js
- **Database**: MongoDB

---

## run project

 Use npm install after cloning to install dependencies

## frontend 

cd/client
- npm run dev 

## backend

cd/server
- node app.js
